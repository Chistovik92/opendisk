# Интерфейс на телефонах — один на Android и iPhone

С 0.6.0 файловый менеджер на Android (Compose) и на iPhone (SwiftUI) устроен
одинаково: те же экраны, те же названия, те же правила. Под ними разное —
поставщик документов на Android, File Provider на iPhone, `MediaStore` и
песочница, — но человек, пересев с одного телефона на другой, не должен
искать кнопки.

Этот файл — договор. Меняя поведение на одной платформе, меняйте его здесь и
на другой. Образец — публичный список функций ES File Explorer; чужого кода
в проекте нет.

Логика, которая не зависит от экрана, написана дважды и проверяется
одинаковыми тестами:

| Что | Android (Kotlin) | iPhone (Swift) |
|---|---|---|
| типы файлов, сортировка, поиск, крошки, диапазон | `FileListing.kt` / `FileListingTest.kt` | `FileListing.swift` / `FileListingTests.swift` |
| закладки, категории | `Categories.kt` / `CategoriesTest.kt` | `Bookmarks.swift` / `FileListingTests.swift` |
| zip | `Archives.kt` / `ArchivesTest.kt` | `ZipArchive.swift` / `ZipArchiveTests.swift` |

Тесты на обеих сторонах проверяют одни и те же случаи: расхождение — ошибка.

## Главный экран

Сверху вниз, разделы с заголовками:

1. **На этом телефоне** — карточки хранилищ: значок, название, «занято X из Y»,
   полоса заполнения. Android: память телефона, карты, root. iPhone: папка
   OpenDisk (видна в «Файлах»).
2. **Категории** — плитки по три в ряд: Изображения, Видео, Звук, Документы,
   Загрузки, Новые. Нажатие открывает файлы категории одним списком.
3. **Закладки** — папки любого диска; строка «значок + имя папки + где лежит»,
   в «⋮» — «Убрать из закладок». Пусто — подсказка, как добавить.
4. **Облака** — как раньше: название, занято/всего, «⋮» с «Показать в Файлах»
   (только Android) и «Удалить».

## Папка

Верхняя панель, три состояния:

- **обычная:** назад, название папки, поиск, переключатель вида, «⋮»;
- **выбор:** ✕, «Выбрано: N», «Выбрать всё»/«Снять выбор»;
- **поиск:** назад и поле «Имя файла или его часть».

Под панелью — **путь ступенями** «Диск › папка › папка». Нажатие на ступень
открывает папку; последняя ступень не нажимается. Длинный путь показывает конец.

Список — три вида, переключатель идёт по кругу **короткий → подробный → плитки**:

- короткий: значок и имя;
- подробный: значок, имя, «размер · дата»; у папки на устройстве — «N элементов»;
- плитки: крупный значок или миниатюра, имя в две строки.

Значок — по типу файла, цвета одинаковые: папка жёлтый, изображение зелёный,
видео красный, звук фиолетовый, документ синий, архив коричневый, приложение
бирюзовый, прочее серый. У картинок на самом устройстве — миниатюра.

Кнопка **«+»** в углу: «Новая папка», «Новый файл». Её нет в режиме выбора,
поиске, категории и пока папка читается.

### Меню «⋮» в папке

Сортировка (имя, размер, дата, тип), «В обратном порядке», «Скрытые файлы»,
«В закладки»/«Убрать из закладок», «Новая папка», «Новый файл», «Обновить».
В категории — без закладки и без создания: у неё нет папки.

### Порядок и фильтры

Папки всегда впереди, при любой сортировке и направлении. Имена сравниваются
без учёта регистра. Скрытые — имя на точку — показываются только по просьбе.
Поиск — по части имени в открытой папке, без рекурсии (обход облака — десятки
тысяч запросов).

## Выбор нескольких файлов

- Долгое нажатие на файл включает режим выбора и отмечает файл.
- В режиме выбора нажатие отмечает/снимает; **долгое нажатие отмечает всё от
  прошлого отмеченного до этого** (диапазон, в любую сторону).
- Нижняя панель: **Копировать, Вырезать, Удалить, Отправить, Ещё**.
  «Отправить» — для одного файла; для нескольких — сообщение «Отправить можно
  только один файл за раз».
- «Ещё»: Переименовать, Свойства, Ссылка на скачивание (где облако умеет) — для
  одного; Скачать в телефон (из облака); Распаковать сюда (один zip на
  устройстве); Сжать в zip (на устройстве).
- Удаление всегда с подтверждением, без возврата.
- Кнопка «назад» сначала закрывает выбор, потом поиск, потом идёт вверх.

## Копирование, перенос, имена

- Копировать/Вырезать кладёт список в буфер; над папкой появляется полоса
  «Скопировано: 3 элемента» с «Отмена» и «Вставить сюда».
- **Имя занято — другое имя, а не перезапись:** «отчёт.pdf» → «отчёт (2).pdf».
  Расширение остаётся в конце. Правило одно для вставки, скачивания и
  распаковки.
- Вырезать и вставить туда же — ничего. Папку в саму себя — отказ.
- **Переименование в занятое имя — отказ** с сообщением «Имя «x» уже занято в
  этой папке.», а не замена соседа.
- Загрузки: «Download/OpenDisk» на Android, папка «Загрузки» внутри OpenDisk на
  iPhone.

## Категории

Файлы одного рода из всех папок устройства, новые первыми, не больше 5000.
Скрытые и служебные пропускаются. «Новые» — добавленные за 7 дней.
Загрузки — только папка загрузок.

- Android: через `MediaStore` по всей основной памяти.
- iPhone: песочница не пускает в чужие файлы, поэтому категории — по папке
  OpenDisk целиком (рекурсивно). Это ограничение системы, а не недоделка.

## Закладки

Список пар «диск + путь», в порядке добавления, без повторов. Хранится в
настройках приложения. Категории в закладки не кладутся.

## Строки

Названия кнопок и сообщений одинаковые на обеих платформах; русский и
английский лежат рядом (`MobileStrings.kt`, `Strings.swift`).
