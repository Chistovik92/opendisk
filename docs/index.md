# OpenDisk

Подключает облачные хранилища как обычные диски. Файлы не скачиваются целиком:
вы открываете папку в проводнике, а нужное подгружается по требованию.

Бесплатная альтернатива Disk-O и Air Explorer. Работает на движке
[rclone](https://rclone.org/) — больше 70 облачных сервисов, — со своим
интерфейсом на Kotlin и Compose Multiplatform.

> **Ранняя стадия разработки.** Основное работает и проверено на Windows
> и Linux, но шероховатости встречаются. Что именно не сделано — честно
> перечислено в конце страницы.

## Скачать

Все сборки — на [странице релизов](https://github.com/Chistovik92/opendisk/releases).

| Система | Файл |
|---|---|
| Windows 10/11, 64 бита | `OpenDisk-*.msi` |
| Debian, Ubuntu, ALT и производные | `opendisk_*_amd64.deb` |
| Fedora, RHEL, openSUSE и производные | `opendisk-*.x86_64.rpm` |
| Любой Linux | `OpenDisk-*-x86_64.AppImage` |
| macOS | `OpenDisk-*.dmg` — **не проверялся** |

### Linux одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/Chistovik92/opendisk/main/scripts/install.sh | sh
```

Скрипт определит пакетный менеджер, скачает подходящий пакет, сверит
контрольную сумму и установит.

## Что умеет

- **Подключение облака как диска** — Яндекс.Диск, Облако Mail.ru, Google Диск,
  Dropbox, OneDrive нажатием плитки; всё остальное — через полный список
  бэкендов rclone с поиском
- **Выбор, что хранить на диске** — от «ничего не кэшировать» до «скачивать
  открытое целиком». Это ответ на главный вопрос: скачивать всё или только то,
  с чем работаешь
- **Изменение подключения** — адрес сервера, логин или пароль меняются без
  пересоздания облака: браузерную авторизацию проходить заново не нужно
- **Автозапуск и автоподключение** — диски появляются сами после входа в систему
- **Ограничение скорости**
- **Русский и английский** интерфейс, по умолчанию как в системе
- **Ничего не нужно доустанавливать**: rclone внутри, драйвер файловой системы
  для Windows ставится из приложения по кнопке

## Чего пока нет

- **macOS не проверялась.** Пакет собирается автоматически, но никто его
  не запускал — Mac у разработчиков нет
- **Android и iOS** — только в планах. Ядро для Android уже собирается
  и проверено на эмуляторе, но приложения ещё нет
- **32-битных сборок не будет**: движок отрисовки не выпускается под x86,
  а 32-битных JDK новее восьмой версии не существует
