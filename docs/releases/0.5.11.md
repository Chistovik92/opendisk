# OpenDisk 0.5.11 — файлы из облака не бьются, сохранённое не теряется

Выпуск по итогам проверки кода на устойчивость: ничего нового снаружи, но
несколько мест, где приложение могло молча испортить или потерять файл.

## Android

- **Недокачанный файл больше не выдаётся как целый.** Файл из облака качался
  сразу под своим итоговым именем. Если телефон выгружал приложение посреди
  загрузки, в следующий раз обрезок считался готовым: фото открывалось
  наполовину, документ не открывался вовсе. Теперь файл качается во
  временный и становится «готовым», только когда размер сошёлся с облаком.
- **Сохранённое без сети уходит в облако само.** Раньше файл, не отправленный
  сразу, ждал, пока облако снова откроют в «Файлах». Теперь отправку доделывает
  система (WorkManager), как только появится сеть, — без значка в шторке.
- **Переименование и перенос не затирают чужие файлы.** Переименовать файл в
  имя, которое в папке уже занято, значило молча заменить соседа — без
  возможности вернуть. Теперь переименование в занятое имя отказывает, а
  перенос, как и копирование, берёт свободное имя «(2)».
- **Кэш не растёт бесконечно.** Каждое открытое из облака видео оставалось в
  памяти телефона навсегда. Теперь кэш держится в пределах десятой части
  свободного места (не больше гигабайта), давно не открытое уходит первым.
- **Отменённое открытие не качает дальше.** Закрыли окно, пока файл
  скачивался, — rclone останавливается, а не тянет гигабайты впустую.
- **Сведения об облаках приходят быстрее.** Место и возможности облаков
  спрашивались по очереди, и медленное облако (Google Диск на общем
  идентификаторе отвечает до полуминуты) держало все остальные. Теперь все
  сразу.

## Windows и Linux

- **Сведения об облаках — тоже все сразу**, как на телефоне.
- **Сетевая ошибка при обновлении списка облаков больше не уходит наружу**:
  пока rclone перезапускается, соединение рвётся, и раньше это не
  перехватывалось.
- **Удаление всегда снимает установленную версию.** Номера версий сравниваются
  как числа, а не как строки — «0.5.9» больше не считается новее «0.5.10».
