# OpenDisk 0.5.12 — «Обновить» работает на всех платформах

С 0.5.6 кнопка «Обновить» на Windows не скачивала новую версию. Этот выпуск
чинит её и добавляет то же самое на Linux, macOS и Android.

## Почему не скачивалось

Установщик качался с пределом 30 секунд на весь запрос, и к тому же сначала
целиком читался в память. Девяносто мегабайт за полминуты — это от 24 Мбит/с;
на медленнее обновление обрывалось всегда, с одним лишь «Не удалось скачать».
Теперь файл пишется на диск по мере загрузки, а оборванным считается только
соединение, молчащее минуту. В кнопке видно, сколько процентов скачано.

## Windows

- **Версии 0.5.0–0.5.11 тоже обновятся.** У них прежний предел в 30 секунд,
  и целый установщик им не скачать. Поэтому под прежним именем
  `OpenDisk-<версия>-x64.exe` теперь лежит маленький веб-установщик
  (полмегабайта): он успевает, а остальное докачивает сам и сверяет с хешем,
  записанным при сборке. Подменённый файл не поставится.
- **Полный установщик** — `OpenDisk-<версия>-x64-offline.exe`: ставится без
  интернета. Его же берёт кнопка «Обновить» начиная с 0.5.12.
- Старые установщики в папке обновлений больше не копятся.

## Linux и macOS

- **«Обновить» ставит сама.** Приложение определяет, как оно установлено
  (deb, rpm, rpm для ALT, AppImage или `OpenDisk.app`), качает тот же вид
  пакета, сверяет контрольную сумму и ставит его после выхода — пакеты через
  `pkexec`, AppImage заменой файла, macOS копией из образа. Потом OpenDisk
  открывается снова.
- **macOS проверен только чтением:** Mac для проверки у разработчиков нет.
  Если что-то не вышло, журнал — `/tmp/opendisk/updates/install-update.log`.

## Android

- **Обновление из приложения.** Раньше проверки обновлений не было вовсе.
  Теперь внизу главного экрана и в «О приложении» есть «Обновить»: apk под
  процессор устройства, сверка SHA-256, системный установщик. Первый раз
  Android попросит разрешить OpenDisk установку приложений; подтверждает
  установку всегда человек.
- Проверку при запуске можно выключить в настройках.
- **0.5.12 на Android нужно поставить руками:** прежние версии обновлять себя
  не умели.
