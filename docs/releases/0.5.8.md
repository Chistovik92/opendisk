# OpenDisk 0.5.8 — облака на телефоне не пропадают, один значок в меню Linux

## Что нового

### Android: облака в «Файлах» больше не пропадают

Две причины, и обе исправлены.

- **Служба уходила при каждом запуске.** Сводку для значка в шторке
  приложение собирало из списка облаков, а его rclone читает несколько секунд
  после запуска. Всё это время выходило «подключённых нет»: служба
  останавливалась, значок исчезал и появлялся снова. Подключённые облака
  теперь берутся из настроек — они известны сразу.
- **После того как система выгружала свёрнутое приложение, служба не
  возвращалась.** Без неё телефон отрезает приложению сеть в фоне, и облако в
  «Файлах» переставало открываться, будто пропало. Теперь служба
  поднимается снова сама.

### Android: облако — это строка, которую открывают

Нажатие на облако открывает его, и больше в строке ничего нет. Показ в
системных «Файлах» и удаление — в меню «⋮» справа. Раньше там стояли
переключатель с непонятной подписью «В «Файлах»» и кнопка «Удалить», по
которой легко было попасть вместо самого облака.

### Linux: OpenDisk в меню один раз

На Simply Linux и других на основе ALT OpenDisk мог оказаться в меню дважды.
До 0.5.2 там ставился пакет для Fedora, и его ярлык не принадлежал ни одному
пакету: при переходе на пакет для ALT он оставался рядом с новым. Теперь
пакет для ALT убирает такой ярлык при установке, а проверка перед выпуском
следит, чтобы ярлык был ровно один.
