# OpenDisk 0.5.9 — обновление на Windows не ломает установку, облака в «Файлах» на запись

## Что нового

### Windows: обновление поверх работающего OpenDisk больше не ломает установку

Если поставить 0.5.8 поверх работающей копии, после перезагрузки OpenDisk
переставал запускаться. Установщик закрывал приложение слишком поздно, уже
после удаления старой версии. Её файлы были заняты, Windows откладывала их
удаление до перезагрузки, а после неё удаляла уже новые файлы с теми же
именами. Теперь установщик сам закрывает OpenDisk и его rclone до того, как
трогать файлы. Запущенный вами отдельно rclone он больше не закрывает.

> **Если OpenDisk после обновления до 0.5.8 не запускается**, просто
> поставьте 0.5.9 поверх — установщик заменит все файлы.

### Windows: обновление не стирает настройки

При каждом обновлении старая версия удаляла свои настройки, как при полном
удалении: закреплённые буквы дисков, тему, язык и автозапуск. Список облаков
не пропадал. Теперь настройки при обновлении остаются, в том числе при
обновлении с 0.5.8: новый установщик сохраняет их до удаления старой версии.
Автозапуск включается снова сам, если галка в настройках стоит.

Если настройки уже стёрло прошлое обновление, их придётся выставить заново.

### Android: облако в «Файлах» — на запись, как обычная папка

До 0.5.9 «Файлы» открывали облако только на чтение. Теперь из «Файлов» и
любого окна выбора файла можно:

- сохранить в облако из любого приложения («Сохранить как…»);
- отредактировать документ прямо в облаке;
- создать файл или папку, переименовать, перенести, скопировать (в том числе
  в другое облако) и удалить.

Сохранённый файл уходит в облако, когда приложение его закрывает. Если сети
нет, файл не теряется и уходит при следующем обращении к облаку.

Заодно исправлено: файл, однажды открытый из облака, раньше отдавался в той
версии, в какой его скачали первый раз, даже если в облаке его уже
заменили. Теперь его копия обновляется.

### Android TV и Wear OS

Тот же apk ставится на приставки Android TV и часы Wear OS. На телевизоре
OpenDisk появляется на главном экране, управляется с пульта и не заезжает за
края экрана. На часах он работает сам, без телефона: вкладки стали
компактными, а на круглом экране есть отступы от краёв. Если на устройстве
нет браузера для входа в облако, OpenDisk прямо об этом говорит. Облакам по
паролю, S3, WebDAV и SFTP браузер не нужен.

Для приставок и часов есть отдельный `-arm32.apk`: у большинства из них
32-битная система даже на 64-битном процессоре. Если не уверены, берите
универсальный.
